# Industrial Sensor Behaviour Analysis and Anomaly Detection

## Project Overview
This project analyses industrial sensor behaviour and identifies unusual patterns using Unsupervised Machine Learning techniques.

## Objectives
- Analyse industrial sensor data.
- Identify patterns in sensor readings.
- Detect potential anomalies.
- Compare different clustering algorithms.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Algorithms
- K-Means Clustering
- Hierarchical Clustering
- DBSCAN

## Project Workflow
1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature Selection and Scaling
4. Clustering
5. Model Evaluation and Comparison
6. Visualisation and Recommendations

## Repository Contents
- Jupyter Notebook containing the project code and analysis.
